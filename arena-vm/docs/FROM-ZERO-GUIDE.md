# PART 0 — Starting assumptions

You begin with only a generic Linux sandbox (Debian-family, x86_64, GCC
toolchain, Python 3.11, git, curl, passwordless sudo for `ldconfig` only).
Nothing related to this project exists yet.

Hard rules of the environment:

1. **Outbound network reaches only `github.com`, `pypi.org`,
   `registry.npmjs.org`** (and their CDNs). No Google, no GNU FTP, no apt
   mirrors, no arbitrary sites. All "downloading" therefore means
   `git clone` from GitHub or `pip` from PyPI.
2. The sandbox may be wiped; only files you commit to Git are durable.
3. Zero budget — FOSS only, no external AI services, no paid tunnels.
4. No credentials in files that get committed.
5. All installs live under the project prefix `local/`; the only privileged
   operation is registering that library path with the dynamic loader.

Before doing anything, verify the base image:

```bash
git --version && gcc --version | head -1 && python3 --version
python3 -m venv /tmp/vprobe && rm -rf /tmp/vprobe && echo venv-ok
sudo -n true && echo sudo-ok
curl -sS -o /dev/null -w 'github %{http_code}\n' --max-time 15 https://github.com
curl -sS -o /dev/null -w 'pypi   %{http_code}\n' --max-time 15 https://pypi.org
df -h . | tail -1     # need ~8 GB free for the full stack including bpy
```

If the venv module is missing or either network probe fails, STOP and report
BLOCKED with the output — there is no in-rules workaround.

# PART 1 — Mental model (what you are building)

```
arena-vm/
├── scripts/   build orchestration, service lifecycle, patches, shims
├── control/   the AI's hands (vmc.py: inject real key/mouse events; shoot.py)
├── config/    Openbox window-manager configuration
├── tests/     acceptance suite + Blender smoke test + env collector
├── docs/      design and status documents
├── evidence/  test outputs (text tracked; media git-ignored)
├── src/       (generated) shallow clones of ~77 upstream repos
├── build/     (generated) out-of-tree builds + markers/ resume flags
├── local/     (generated) the install prefix: bin, lib, venv, etc, fonts…
└── run/       (generated) PIDs, logs, .Xauthority, tablet credentials
```

Runtime topology: **Xvfb** is a virtual monitor on display `:99`
(1280x800x24). **Openbox** is its window manager. GUI apps (st, dillo, vim,
ranger) draw into that virtual display. `control/vmc.py` injects XTEST
keyboard/mouse events and takes screenshots, closing the perception/action
loop. **x11vnc** mirrors the display on loopback port 5900; **websockify +
noVNC** expose it on port 6080 behind HTTP Basic auth for a tablet browser.
Blender runs headless through the `bpy` Python wheel and renders on CPU with
Cycles (no GPU exists, so EEVEE/EGL paths are impossible by design).

````markdown
# PART E — Maintenance, repair, and extension

## E.1 The marker system and resuming a failed build

Each successful stage creates `build/markers/<stage>`. On re-run, existing
markers skip the stage. To rebuild one stage:

```bash
rm -f build/markers/pango
bash scripts/build_openbox.sh pango          # stage name = function minus s_
# then re-run the master to continue and restart services:
bash scripts/recover.sh
```

Stage-to-script map: build_stack (X11/Xvfb), build_apps (toolchain/dillo/vim),
build_suckless (ncurses/dwm/st/dmenu), build_openbox (glib chain + WM),
build_extras (Blender libs).

## E.2 Adding a new source dependency

1. Add `name|owner/repo|ref|purpose` to `scripts/manifest.env` (`-` = default
   branch; a tag string pins a release).
2. `bash scripts/fetch.sh name` — clones it and appends `PIN_name=<sha>` to
   pins.env.
3. Add `s_name()` to the relevant build script using a helper from env.sh:
   `conf_build "$VM_SRC/name"` (autotools), `meson_build "$VM_SRC/name" -Dopt=…`,
   `cmake_build "$VM_SRC/name" -DFLAG=…`, or `make_build "$VM_SRC/name"`.
4. Add it to that script's `all)` dispatch in dependency order.
5. Build, then extend/run `tests/acceptance.sh`. Commit the manifest, pins,
   and script changes.

## E.5 Troubleshooting table (real failures, already diagnosed)

| Symptom | Root cause | Remedy |
|---|---|---|
| `autoreconf: command not found` in build_openbox | autotools are built by build_apps | Keep recover.sh order: apps → suckless → openbox |
| `cannot find -lncursesw` / `-ltinfo` | Host image has versioned runtime `.so.6` but no dev symlink | `build_stack.sh syslinks` creates absolute symlinks in local/lib |
| vim configure: `tgetent() NOT FOUND` | Debian splits tgetent into libtinfo; not linked transitively | s_vim picks `--with-tlib=tinfo` when local/lib/libtinfo.so exists |
| ncurses `DSO missing from command line` in test/ | Test binaries assume transitive tinfo linkage | ncurses configured `--without-tests` |
| bison `#error Please port gnulib fseterr.c` | glibc ≥2.32 hides `_IO_ftrylockfile` | bison-fseterr-glibc.patch via apply_patch (idempotent) |
| bison VCS bootstrap fails (flex/autopoint/gnulib) | flex is unobtainable inside the allowlist | Use bison 3.0.4 release mirror; see docs/bison-source-notes.md |
| xkbcommon: `bison found 3.0.4 but need >=3.6` | Hard version gate; grammar is compatible | Gate removed; `parse.error detailed`→`verbose` in build_extras.sh |
| pkgconf `Dependency xft not found` | pkgconf 3.x is case-sensitive; file is Xft.pc | s_pango creates a `xft.pc` symlink |
| meson "not boolean / unknown option" | Feature vs boolean option typing | Use `enabled/disabled/auto` for feature opts, `true/false` for booleans |
| autopoint substitution produced an empty file | Multi-line version string broke a sed expression | s_gettext pipes `--version | head -1` and guards with `[ -s ]` |
| ranger `setupterm: could not find terminfo` | Needs local ncurses DB and a real TERM | env.sh exports TERMINFO; run with `TERM=xterm-256color` |
| bpy `libxkbcommon.so.0 cannot open` then `libGL.so.1` | Wheel dlopens system-style libs at runtime | env.sh LD_LIBRARY_PATH; glvnd built with `-Dglx=enabled` |
| Blender EEVEE `Couldn't open libEGL` | No GPU/EGL in the sandbox | Use Cycles CPU (blender_smoke.py already does); EEVEE is infeasible |
| dillo "Could not establish connection" | Egress allowlist blocks external sites | Expected; demo with file:// pages, never claim web access works |
| Port 6080 returns 401 | HTTP Basic auth challenge | Correct behavior; 200 only with `-u "$(cat run/tablet.cred)"` |
| Form field ignores typed text in dillo | XTEST click doesn't focus the field | Focus window, `key Tab` into the field, then `type` |
| make tries to regenerate configure and fails | Git clones have uniform mtimes | pin_timestamps normalizes source mtimes to 2020-01-01 |
| All binaries gone after a sandbox reset | local/build/src are not persisted | re-sync Git (C.1) and rerun recover.sh (C.2) |

| `stage x: command not found` with hyphenated names | Dispatch builds `s_$1` from the argument | Use underscore stage names (e.g. `openbox_config`); aliases are wired where needed |
````

## SCRIPTS — ORCHESTRATION

### File: `scripts/env.sh`

_Sourced by every build script: path variables, compiler flags, helper functions._

````bash
# Sourced by every build script. Defines the local toolchain/prefix environment.
# All builds are relocatable inside arena-vm/ and need no root access.
export VM_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
export VM_SRC="$VM_ROOT/src"
export VM_BUILD="$VM_ROOT/build"
export VM_PREFIX="$VM_ROOT/local"
export VM_VENV="$VM_PREFIX/venv"

mkdir -p "$VM_SRC" "$VM_BUILD" "$VM_PREFIX/lib/pkgconfig" "$VM_PREFIX/share/pkgconfig"

# Python tooling (meson/ninja/cmake) live in the venv
export PATH="$VM_VENV/bin:$VM_PREFIX/bin:$PATH"

# pkg-config (pkgconf) once built; before that these vars are harmless
export PKG_CONFIG_PATH="$VM_PREFIX/lib/pkgconfig:$VM_PREFIX/share/pkgconfig"
export PKG_CONFIG_SYSROOT_DIR="/"
export PKG_CONFIG_LIBDIR="$VM_PREFIX/lib/pkgconfig:$VM_PREFIX/share/pkgconfig:/usr/lib/x86_64-linux-gnu/pkgconfig:/usr/share/pkgconfig"

# Compiler flags: find local headers/libs and bake an rpath into every binary
export CPPFLAGS="-I$VM_PREFIX/include"
export CFLAGS="-O2 -g0 -pipe -I$VM_PREFIX/include"
export CXXFLAGS="-O2 -g0 -pipe -I$VM_PREFIX/include"
export LDFLAGS="-L$VM_PREFIX/lib -Wl,-rpath,$VM_PREFIX/lib -Wl,-rpath-link,$VM_PREFIX/lib"
export LIBRARY_PATH="$VM_PREFIX/lib"
# Runtime loader path for prebuilt wheels (bpy) that find system-style libs
# like libxkbcommon.so.0 at dlopen time rather than via build rpath.
[ "${VM_LD_PATH_SET:-}" = 1 ] || export LD_LIBRARY_PATH="$VM_PREFIX/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
VM_LD_PATH_SET=1

# Terminfo from the locally built ncurses (st/ranger/vim curses support)
[ -d "$VM_PREFIX/share/terminfo" ] && export TERMINFO="$VM_PREFIX/share/terminfo"
export C_INCLUDE_PATH="$VM_PREFIX/include"
export CPLUS_INCLUDE_PATH="$VM_PREFIX/include"

# Meson default options (used by meson_setup helper)
export VM_MESON_COMMON=(--prefix="$VM_PREFIX" --libdir=lib --buildtype=debugoptimized -Ddefault_library=shared -Db_lundef=false)

log()  { printf '\n\033[1;36m[VM]\033[0m %s\n' "$*"; }
fail() { printf '\n\033[1;31m[FAIL]\033[0m %s\n' "$*" >&2; exit 1; }

# Idempotently apply scripts/patches/<name>.patch to a source tree
apply_patch() {
  local src="$1"
  local name="$2"
  local p="$VM_ROOT/scripts/patches/$name.patch"
  [ -f "$p" ] || { log "no patch $name, skip"; return 0; }
  if ( cd "$src" && patch -R -p1 --dry-run -s < "$p" ) 2>/dev/null; then
    log "patch $name already applied"; return 0
  fi
  log "apply patch $name"
  ( cd "$src" && patch -N -p1 --no-backup-if-mismatch -s < "$p" ) || fail "patch $name"
}

# Pin every mtime in a source tree to one fixed timestamp. GNU make treats
# equal mtimes as up-to-date, which neutralizes autotools remake rules that
# would otherwise demand autoreconf tools absent from this image.
pin_timestamps() {
  local src="$1"
  find "$src" -type f -exec touch -h -d '2020-01-01 00:00:00 UTC' {} +
}

# configure-based build (autotools dist trees carry a pre-generated configure)
conf_build() {
  local src="$1"; shift
  log "configure+make: $(basename "$src")"
  pin_timestamps "$src"
  rm -rf "$VM_BUILD/b-$(basename "$src")"
  mkdir -p "$VM_BUILD/b-$(basename "$src")"
  ( cd "$VM_BUILD/b-$(basename "$src")" && \
    "$src/configure" --prefix="$VM_PREFIX" --libdir="$VM_PREFIX/lib" "$@" && \
    make -j"$(nproc)" && make install ) || fail "conf_build $src"
}

# meson-based build; args after src are meson options
meson_build() {
  local src="$1"; shift
  local name
  name="$(basename "$src")"
  log "meson: $name"
  rm -rf "$VM_BUILD/m-$name"
  meson setup "$VM_BUILD/m-$name" "$src" "${VM_MESON_COMMON[@]}" "$@" || fail "meson setup $name"
  meson compile -C "$VM_BUILD/m-$name" || fail "meson compile $name"
  meson install -C "$VM_BUILD/m-$name" || fail "meson install $name"
}

# cmake-based build
cmake_build() {
  local src="$1"; shift
  local name
  name="$(basename "$src")"
  log "cmake: $name"
  rm -rf "$VM_BUILD/c-$name"
  cmake -S "$src" -B "$VM_BUILD/c-$name" \
    -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$VM_PREFIX" \
    -DCMAKE_INSTALL_LIBDIR=lib -DCMAKE_SKIP_RPATH=OFF \
    -DCMAKE_INSTALL_RPATH="$VM_PREFIX/lib" -DCMAKE_BUILD_WITH_INSTALL_RPATH=ON "$@" || fail "cmake $name"
  cmake --build "$VM_BUILD/c-$name" -j"$(nproc)" || fail "cmake build $name"
  cmake --install "$VM_BUILD/c-$name" || fail "cmake install $name"
}

# plain makefile build (suckless-style); pass extra make vars as args
make_build() {
  local src="$1"; shift
  log "make: $(basename "$src")"
  make -C "$src" -j"$(nproc)" PREFIX="$VM_PREFIX" "$@" || fail "make $src"
  make -C "$src" PREFIX="$VM_PREFIX" "$@" install || fail "make install $src"
````

### File: `scripts/fetch.sh`

_Clones every manifest repo into src/ and records resolved SHAs in pins.env._

````bash
#!/usr/bin/env bash
# Shallow-clone every manifest repo and pin its exact commit in pins.env.
# Manifest columns: name | owner/repo | ref (- = default branch) | purpose.
# Usage: fetch.sh [name ...]   (no args = everything)
set -euo pipefail
source "$(dirname "$0")/env.sh"
MANIFEST="$VM_ROOT/scripts/manifest.env"
PINS="$VM_ROOT/pins.env"
touch "$PINS"

want=("$@")
FAILURES=()
while IFS='|' read -r name repo ref purpose; do
  [ -z "${name:-}" ] && continue
  case "$name" in \#*) continue;; esac
  name="$(echo "$name" | tr -d ' ')"
  repo="$(echo "$repo" | tr -d ' ')"
  ref="$(echo "$ref" | tr -d ' ')"
  if [ "${#want[@]}" -gt 0 ]; then
    ok=0; for w in "${want[@]}"; do [ "$w" = "$name" ] && ok=1; done
    [ "$ok" = 0 ] && continue
  fi
  # noVNC installs under the prefix, every other checkout under src/
  if [ "$name" = "novnc" ]; then
    dst="$VM_PREFIX/share/novnc"
  else
    dst="$VM_SRC/$name"
  fi
  if [ -d "$dst/.git" ]; then
    log "exists: $name"
  else
    log "clone $repo ($ref) -> $name"
    if [ "$ref" = "-" ]; then
      git clone --depth 1 "https://github.com/$repo.git" "$dst" 2>&1 | tail -2 || FAILURES+=("$name|$repo")
    else
      git clone --depth 1 --branch "$ref" "https://github.com/$repo.git" "$dst" 2>&1 | tail -2 || FAILURES+=("$name|$repo")
    fi
  fi
  [ -d "$dst/.git" ] || continue
  sha=$(git -C "$dst" rev-parse HEAD)
  if grep -q "^PIN_${name}=" "$PINS"; then
    sed -i "s|^PIN_${name}=.*|PIN_${name}=$sha   # $repo ($ref)|" "$PINS"
  else
    echo "PIN_${name}=$sha   # $repo ($ref)" >> "$PINS"
  fi
done < "$MANIFEST"
log "pins written to $PINS"
if [ "${#FAILURES[@]}" -gt 0 ]; then
  echo "CLONE FAILURES:" >&2
  printf '  %s\n' "${FAILURES[@]}" >&2
  exit 2
fi
````

````bash
# Optional extras for the Blender (bpy) wheel: bison, libxkbcommon, glvnd.
# Kept separate from build_stack.sh so a toolchain gap can never block the
# desktop build. bison comes from a release-tarball mirror: VCS snapshots

  # scan-*.c / parse-gram.c, configure and Makefile.in: no flex or gnulib
  # bootstrap needed. See docs/bison-source-notes.md for the rejected VCS path.
  [ -d "$VM_SRC/bison-rel" ] || git clone --depth 1 \
````

# PART 4 — How to download apps (the only two legal channels)

## 4.1 GitHub source packages — `scripts/fetch.sh` + `scripts/manifest.env`

Every compiled component is described by one manifest line:

```text
name|owner/repo|ref|purpose
```

- `name` becomes the checkout directory `src/<name>` and the pin variable
  `PIN_<name>`.
- `ref` of `-` means "default branch"; anything else (e.g. `v3.4.6`,
  `2.80.4`, `pcre2-10.44`) is checked out as a tag for a stable, reproducible
  build.
- fetch.sh runs `git clone --depth 1` (adding `--branch <tag>` when needed),
  then writes the resolved 40-character SHA into `pins.env`. That file is the
  evidence that every rebuild compiles the identical upstream commits.

Fetch everything, or one package:

```bash
bash scripts/fetch.sh                 # all manifest entries
bash scripts/fetch.sh glib pango      # just these two
```

A failed clone makes fetch.sh exit 2 and print `CLONE FAILURES:` — the only
legal response is to retry (network blip) or choose another GitHub mirror;
never reach for a non-allowlisted host.

### Adding a new app from source

1. Append `myapp|some-org/myapp|-|what it is for` to `scripts/manifest.env`.
2. `bash scripts/fetch.sh myapp` — creates `src/myapp` and its pin.
3. Add an `s_myapp()` function to the appropriate build script using the
   env.sh helpers:
   - autotools release tree: `conf_build "$VM_SRC/myapp" --prefix=…` (the
     helper already supplies prefix/libdir and parallel make);
   - meson: `meson_build "$VM_SRC/myapp" -Dopt=value`;
   - cmake: `cmake_build "$VM_SRC/myapp" -DFLAG=ON`;
   - plain makefile (suckless style): `make_build "$VM_SRC/myapp"`.
4. Put `stage myapp s_myapp` into that script's `all)` dispatch in
   dependency order, then run `bash <script> myapp`.

- Anything outside the three allowed hosts (Google, GNU FTP, apt repos…).

# PART 8 — Fixing anything that breaks

## 8.1 Debugging method

1. The build stops with `[FAIL] stage <name> failed`. Note the stage name.
2. Find its function `s_<name>` in the matching script and its build
   directory: autotools → `build/b-<name>/config.log`, meson →
   `build/m-<name>/meson-logs/meson-log.txt`, cmake → `build/c-<name>/`.
3. Fix the root cause (table below covers every failure seen so far).
4. Delete the stage marker if one was written, re-run the single stage,
   then re-run `recover.sh` to continue from where it stopped.
5. Re-run `tests/acceptance.sh`; never claim success without it.

## 8.2 Symptom → cause → exact fix

| Symptom | Cause | Fix |
|---|---|---|
| `autoreconf: command not found` in build_openbox | autotools come from build_apps | Keep recover.sh order: apps → suckless → openbox; run `bash scripts/build_apps.sh all` first |
| `cannot find -lncursesw` / `-ltinfo` | Base image ships versioned runtime `.so.6` but no unversioned dev symlink | `bash scripts/build_stack.sh syslinks` (absolute symlinks into local/lib) |
| vim configure `tgetent() NOT FOUND` | tgetent lives in libtinfo and is not linked transitively | s_vim selects `--with-tlib=tinfo` when local/lib/libtinfo.so exists; ensure the syslinks stage ran |
| ncurses make `DSO missing from command line` in test/ | Test binaries assume transitive tinfo linkage | ncurses is configured `--without-tests`; do not re-enable tests |
| bison `#error Please port gnulib fseterr.c` | glibc ≥2.32 hides `_IO_ftrylockfile` | scripts/patches/bison-fseterr-glibc.patch is applied idempotently via apply_patch in build_extras.sh |
| bison VCS bootstrap failures (flex/autopoint/gnulib) | flex is unobtainable inside the allowlist | Use the bison 3.0.4 release-tarball mirror (tar-mirror/gnu-bison); rationale in docs/bison-source-notes.md |
| xkbcommon meson `found 3.0.4 but need >=3.6` | Hard version gate; the grammar is compatible with 3.0.4 | build_extras.sh strips the gate and maps `parse.error detailed`→`verbose` |
| pkgconf `Dependency "xft" not found` | pkgconf 3.x is case-sensitive; the file is Xft.pc | s_pango symlinks `xft.pc → Xft.pc` in local/lib/pkgconfig |
| meson "value disabled is not boolean" / "unknown option" | feature options take enabled/disabled/auto; booleans take true/false | Match the type in meson_options.txt before retrying the stage |
| autopoint step produced an empty script | A multi-line `--version` string broke a sed expression | s_gettext uses `head -1` and an `[ -s ]` guard; rerun `build_openbox.sh gettext` |
| ranger `setupterm: could not find terminfo database` | curses needs the local terminfo DB and a real TERM | env.sh exports TERMINFO; launch with `TERM=xterm-256color` |
| bpy import: `libxkbcommon.so.0 cannot open` then `libGL.so.1` | The wheel dlopens system-style libs at runtime | env.sh sets LD_LIBRARY_PATH to local/lib; glvnd is built with `-Dglx=enabled` |
| Blender `Couldn't open libEGL.so.1` | No GPU/EGL in the sandbox | Use Cycles CPU (the smoke test already does); EEVEE is infeasible, not broken |
| dillo "Could not establish connection" | Egress allowlist blocks external websites | Expected behavior; demonstrate the browser with `file://` pages |
| Port 6080 returns 401 | HTTP Basic auth challenge | Correct; 200 requires `-u "$(cat run/tablet.cred)"` |
| dillo form field ignores typed text | XTEST clicks do not focus web inputs reliably | Focus the window, `vmc.py key Tab` into the field, then `vmc.py type` |
| make tries to regenerate configure and fails | Git clones flatten mtimes, triggering remake rules | pin_timestamps normalizes source mtimes to 2020-01-01; helpers already call it |
| All binaries vanish after a sandbox reset | src/build/local/run are not persisted | Re-sync Git and rerun recover.sh — the whole design exists for this |
| Tablet bridge dies after a desktop restart | x11vnc binds to a specific Xvfb process | Rerun start_tablet.sh after start_desktop.sh |
| `stage x: command not found` for a hyphenated stage | Dispatch evaluates `s_$1` literally | Use underscore names (openbox_config); hyphen aliases are wired where needed |
| A source repo needs manual edits on every fresh fetch | Clones are disposable | Encode the edit as a scripts/patches/*.patch plus apply_patch, like the bison fix |

_THE agent control surface: XTEST keyboard/mouse injection, screenshots, windows._

````python
#!/usr/bin/env python3
"""vmc - Arena agent control surface for the virtual X11 desktop.

All operations use XTEST extension injection against the live Xvfb display,
so input reaches real applications exactly as a physical keyboard/mouse would.

Subcommands:
  info                              screen geometry + pointer position
  shot [file.png]                   capture the screen (prints path)
  windows                           list windows (id, title, geometry)
  focus <window_id>                 raise+focus a window
  close <window_id>                 send WM_DELETE_WINDOW
  move <x> <y>                      warp pointer
  mousedown [button] / mouseup [button]
  click [button] [x] [y]            button 1=left 2=middle 3=right (default 1)
  doubleclick [x] [y]
  scroll <clicks>                   positive=down, negative=up (wheel)
  key <keysym> [keysym...]          e.g. key Return | key ctrl shift t
  type <string>                     type arbitrary text
  launch <program> [args...]        start a GUI program on the display
  wait-title <substring> [seconds]  poll until a window title contains text
  exec <shell command>              run a shell command with desktop env set
  keysyms                           list available keysym names (first 80)
"""
import os
import sys
import time
import subprocess

from Xlib import X, XK, display
from Xlib.ext import xtest
from Xlib.protocol.event import ClientMessage

VM_PREFIX = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", "local"))
DISPLAY = os.environ.setdefault("DISPLAY", ":99")
os.environ.setdefault("LD_LIBRARY_PATH", VM_PREFIX + "/lib")
os.environ.setdefault("FONTCONFIG_PATH", VM_PREFIX + "/etc/fonts")
os.environ.setdefault("TERM", "xterm-256color")

# US-layout unshifted punctuation -> keysym name
NAME_MAP = {
    '-': 'minus', '=': 'equal', '[': 'bracketleft', ']': 'bracketright',
    '\\': 'backslash', ';': 'semicolon', "'": 'apostrophe', '`': 'grave',
    ',': 'comma', '.': 'period', '/': 'slash', ' ': 'space',
}
# US-layout shifted symbols -> unshifted keysym name
SHIFT_MAP = {
    '~': 'grave', '!': '1', '@': '2', '#': '3', '$': '4', '%': '5', '^': '6',
    '&': '7', '*': '8', '(': '9', ')': '0', '_': 'minus', '+': 'equal',
    '{': 'bracketleft', '}': 'bracketright', '|': 'bar', ':': 'semicolon',
    '"': 'quotedbl', '<': 'comma', '>': 'period', '?': 'slash',
    'A': 'a', 'B': 'b', 'C': 'c', 'D': 'd', 'E': 'e', 'F': 'f', 'G': 'g',
    'H': 'h', 'I': 'i', 'J': 'j', 'K': 'k', 'L': 'l', 'M': 'm', 'N': 'n',
    'O': 'o', 'P': 'p', 'Q': 'q', 'R': 'r', 'S': 's', 'T': 't', 'U': 'u',
    'V': 'v', 'W': 'w', 'X': 'x', 'Y': 'y', 'Z': 'z',
}


class Desktop:
    def __init__(self):
        self.d = display.Display(DISPLAY)
        if not self.d.has_extension("XTEST"):
            sys.exit("XTEST extension unavailable on " + DISPLAY)
        self.root = self.d.screen().root
        # spare keycode used as a scratch mapping for keysyms without one
        self._scratch_keycode = 255
        self._scratch_restore = None

    # ---------- basics ----------
    def screen_size(self):
        g = self.root.get_geometry()
        return g.width, g.height

    def pointer(self):
        p = self.root.query_pointer()
        return p.root_x, p.root_y

    def sync(self):
        self.d.sync()
        time.sleep(0.05)

    # ---------- screenshots ----------
    def shot(self, path):
        import mss
        from PIL import Image
        with mss.MSS(display=DISPLAY) as sct:
            mon = sct.monitors[0]
            raw = sct.grab(mon)
            img = Image.frombytes("RGB", raw.size, raw.bgra, "raw", "BGRX")
        os.makedirs(os.path.dirname(os.path.abspath(path)), exist_ok=True)
        img.save(path)
        return os.path.abspath(path)

    # ---------- mouse ----------
    def move(self, x, y):
        xtest.fake_input(self.d, X.MotionNotify, x=x, y=y)
        self.sync()

    def button(self, button, down=True):
        ev = X.ButtonPress if down else X.ButtonRelease
        xtest.fake_input(self.d, ev, button)
        self.sync()

    def click(self, button=1, x=None, y=None):
        if x is not None and y is not None:
            self.move(x, y)
        self.button(button, True)
        self.button(button, False)

    def doubleclick(self, x=None, y=None):
        self.click(1, x, y)
        self.click(1)

    def scroll(self, clicks):
        for _ in range(abs(int(clicks))):
            self.button(5 if clicks > 0 else 4)  # 5=down 4=up

    # ---------- keyboard ----------
    def _keycode(self, keysym_name):
        ks = XK.string_to_keysym(keysym_name)
        if ks == 0:
            raise ValueError(f"unknown keysym {keysym_name!r}")
        kc = self.d.keysym_to_keycode(ks)
        if kc:
            return kc, False
        # no physical key: temporarily bind the keysym to the scratch keycode
        mapping = self.d.get_keyboard_mapping(self._scratch_keycode, 1)
        if self._scratch_restore is None:
            self._scratch_restore = mapping
        mapping[0] = (ks, 0, 0, 0, 0, 0, 0, 0, 0)
        self.d.change_keyboard_mapping(self._scratch_keycode, [mapping[0]])
        self.sync()
        return self._scratch_keycode, True

    KEY_ALIASES = {
        "ctrl": "Control_L", "control": "Control_L", "ctl": "Control_L",
        "shift": "Shift_L", "alt": "Alt_L", "mod1": "Alt_L",
        "super": "Super_L", "win": "Super_L", "mod4": "Super_L",
        "esc": "Escape", "return": "Return", "enter": "Return",
        "ret": "Return", "del": "Delete", "ins": "Insert",
        "pgup": "Prior", "pgdn": "Next", "pageup": "Prior", "pagedown": "Next",
        "bs": "BackSpace", "backspace": "BackSpace", "spacebar": "space",
        "left": "Left", "right": "Right", "up": "Up", "down": "Down",
        "tab": "Tab", "caps": "Caps_Lock", "print": "Print",
    }

    def key(self, *names):
        """Press a chord or single key, e.g. key('ctrl','shift','t')."""
        names = [self.KEY_ALIASES.get(n.lower(), n) for n in names]
        codes = [self._keycode(n) for n in names]
        for kc, _ in codes:
            xtest.fake_input(self.d, X.KeyPress, kc)
        self.sync()
        for kc, _ in reversed(codes):
            xtest.fake_input(self.d, X.KeyRelease, kc)
        self.sync()

    def type(self, text):
        for ch in text:
            if ch == "\n":
                self.key("Return")
                continue
            if ch == "\t":
                self.key("Tab")
                continue
            if ch == " ":
                self.key("space")
                continue
            shifted = ch in SHIFT_MAP
            name = SHIFT_MAP.get(ch, NAME_MAP.get(ch, ch))
            kc, scratch = self._keycode(name)
            if shifted:
                xtest.fake_input(self.d, X.KeyPress, self.d.keysym_to_keycode(XK.string_to_keysym("Shift_L")))
            xtest.fake_input(self.d, X.KeyPress, kc)
            self.sync()
            xtest.fake_input(self.d, X.KeyRelease, kc)
            if shifted:
                xtest.fake_input(self.d, X.KeyRelease, self.d.keysym_to_keycode(XK.string_to_keysym("Shift_L")))
            self.sync()

    # ---------- windows ----------
    def windows(self):
        out = []

        def walk(win, depth=0):
            try:
                attrs = win.get_attributes()
                if attrs.map_state != X.IsViewable:
                    return
                name = win.get_wm_name()
                if not name:
                    name = ""
                if isinstance(name, bytes):
                    name = name.decode("utf-8", "replace")
                g = win.get_geometry()
                out.append((win.id, name, g.x, g.y, g.width, g.height))
                for child in win.query_tree().children:
                    walk(child, depth + 1)
            except Exception:
                pass

        for child in self.root.query_tree().children:
            walk(child)
        return out

    # EWMH top-level managed clients (frame windows excluded), with the
    # UTF-8 _NET_WM_NAME title that python-xlib's get_wm_name() can miss.
    def clients(self):
        atom_list = self.d.intern_atom("_NET_CLIENT_LIST")
        atom_name = self.d.intern_atom("_NET_WM_NAME")
        raw = self.root.get_full_property(atom_list, X.AnyPropertyType)
        out = []
        for wid in (raw.value if raw else []):
            win = self.d.create_resource_object("window", wid)
            try:
                g = win.get_geometry()
                prop = win.get_full_property(atom_name, 0)
                name = prop.value.decode("utf-8", "replace") if prop else ""
                out.append((win.id, name, g.x, g.y, g.width, g.height))
            except Exception:
                pass
        return out

    def close_all(self):
        for wid, *_ in self.clients():
            try:
                self.close(hex(wid))
            except Exception:
                pass
        self.d.sync()

    def focus(self, wid):
        win = self.d.create_resource_object("window", int(wid, 0))
        win.set_input_focus(X.RevertToPointerRoot, X.CurrentTime)
        self.d.sync()

    def close(self, wid):
        win = self.d.create_resource_object("window", int(wid, 0))
        wm_protocols = self.d.intern_atom("WM_PROTOCOLS")
        wm_delete = self.d.intern_atom("WM_DELETE_WINDOW")
        ev = ClientMessage(display=self.d, window=win, client_type=wm_protocols,
                           data=(32, [wm_delete, X.CurrentTime, 0, 0, 0]))
        win.send_event(ev)
        self.d.sync()

    # ---------- launching ----------
    def launch(self, argv):
        env = dict(os.environ)
        env["DISPLAY"] = DISPLAY
        p = subprocess.Popen(argv, stdout=subprocess.DEVNULL,
                             stderr=subprocess.DEVNULL, stdin=subprocess.DEVNULL,
                             start_new_session=True, env=env)
        return p.pid

    def wait_title(self, substring, timeout=10):
        deadline = time.time() + timeout
        while time.time() < deadline:
            for wid, name, *_ in self.windows():
                if substring.lower() in name.lower():
                    return wid
            time.sleep(0.3)
        return None


def main():
    if len(sys.argv) < 2:
        print(__doc__)
        sys.exit(1)
    cmd, args = sys.argv[1], sys.argv[2:]
    desk = Desktop()

    if cmd == "info":
        w, h = desk.screen_size()
        x, y = desk.pointer()
        print(f"display={DISPLAY} screen={w}x{h} pointer=({x},{y})")
    elif cmd == "shot":
        path = args[0] if args else os.path.join(
            os.path.dirname(__file__), "..", "evidence", "shot.png")
        print(desk.shot(path))
    elif cmd == "windows":
        rows = desk.windows()
        if not rows:
            print("(no viewable windows)")
        for wid, name, x, y, w, h in rows:
            print(f"0x{wid:08x}  {w}x{h}+{x}+{y}  {name}")
    elif cmd == "clients":
        rows = desk.clients()
        if not rows:
            print("(no managed clients)")
        for wid, name, x, y, w, h in rows:
            print(f"0x{wid:08x}  {w}x{h}+{x}+{y}  {name}")
    elif cmd == "closeall":
        desk.close_all()
        print("closed all managed clients")
    elif cmd == "focus":
        desk.focus(args[0])
    elif cmd == "close":
        desk.close(args[0])
    elif cmd == "move":
        desk.move(int(args[0]), int(args[1]))
    elif cmd == "mousedown":
        desk.button(int(args[0] if args else 1), True)
    elif cmd == "mouseup":
        desk.button(int(args[0] if args else 1), False)
    elif cmd == "click":
        b = int(args[0]) if len(args) >= 1 and args[0].isdigit() else 1
        if len(args) >= 3:
            desk.click(b, int(args[-2]), int(args[-1]))
        else:
            desk.click(b)
    elif cmd == "doubleclick":
        if len(args) >= 2:
            desk.doubleclick(int(args[0]), int(args[1]))
        else:
            desk.doubleclick()
    elif cmd == "scroll":
        desk.scroll(int(args[0]))
    elif cmd == "key":
        desk.key(*args)
    elif cmd == "type":
        desk.type(args[0])
    elif cmd == "launch":
        print("pid", desk.launch(args))
    elif cmd == "wait-title":
        to = float(args[1]) if len(args) > 1 else 10
        wid = desk.wait_title(args[0], to)
        print(f"0x{wid:08x}" if wid else "TIMEOUT")
        sys.exit(0 if wid else 1)
    elif cmd == "exec":
        os.execvp("bash", ["bash", "-c", args[0]])
    elif cmd == "keysyms":
        names = [n for n in dir(XK) if n.startswith("XK_")][:80]
        print("\n".join(n[3:] for n in names))
    else:
        print(f"unknown command: {cmd}", file=sys.stderr)
        print(__doc__)
        sys.exit(2)


if __name__ == "__main__":
    main()
````

````python
import os
from Xlib import display, X

# deep slate blue, easy on the eyes behind st/dillo
BG = (0x1c, 0x25, 0x33)

root = d.screen().root

pixel = cmap.alloc_color(BG[0] << 8, BG[1] << 8, BG[2] << 8).pixel
root.change_attributes(background_pixel=pixel)

d.sync()
d.close()
````

````bash
#!/usr/bin/env bash
# Acceptance tests against the live desktop. Writes evidence/acceptance.txt
# with PASS/FAIL/BLOCKED/NOT TESTED for every requirement.
set -uo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
source "$HERE/../scripts/env.sh"
export DISPLAY="${DISPLAY:-:99}"
PY="$VM_VENV/bin/python"
EV="$VM_ROOT/evidence"; mkdir -p "$EV"
RES="$EV/acceptance.txt"; : > "$RES"
ok=0; fail=0; blocked=0

rec() { # status name [detail]
  printf '%-8s %-34s %s\n' "$1" "$2" "${3:-}" | tee -a "$RES"
  case "$1" in PASS) ok=$((ok+1));; FAIL) fail=$((fail+1));; BLOCKED) blocked=$((blocked+1));; esac
}

# 1. display server alive
if pgrep -f "bin/Xvfb $DISPLAY" >/dev/null; then rec PASS T1_xvfb_running "$(pgrep -af "bin/Xvfb $DISPLAY" | head -1)"; else rec FAIL T1_xvfb_running; fi

# 2. X11 client connects
if "$VM_PREFIX/bin/xdpyinfo" >/dev/null 2>&1; then rec PASS T2_x11_client_connect "$("$VM_PREFIX/bin/xdpyinfo" | awk '/X.Org version/{print $3}')"; else rec FAIL T2_x11_client_connect; fi

# 3. window manager (openbox is the required WM; dwm retained as fallback)
if pgrep -f "bin/openbox" >/dev/null; then
  WM_NAME=$("$VM_PREFIX/bin/xprop" -root _NET_SUPPORTING_WM_CHECK 2>/dev/null \
    | awk '{print $5}' \
    | xargs -r -I{} "$VM_PREFIX/bin/xprop" -id {} _NET_WM_NAME 2>/dev/null \
    | cut -d'"' -f2)
  rec PASS T3_window_manager "${WM_NAME:-openbox} pid $(pgrep -f bin/openbox | head -1)"
elif pgrep -f "bin/dwm" >/dev/null; then
  rec PASS T3_window_manager "dwm(fallback) pid $(pgrep -f bin/dwm | head -1)"
else rec FAIL T3_window_manager; fi

# 4. screenshot of the live display
if "$PY" "$VM_ROOT/control/shoot.py" "$EV/t4_shot.png" >/dev/null 2>&1 && [ -s "$EV/t4_shot.png" ]; then rec PASS T4_screenshot "$(stat -c%s "$EV/t4_shot.png") bytes"; else rec FAIL T4_screenshot; fi

# 5. GUI app launch + 6. injected input changes state + 8. file created via GUI
# deterministic desktop: close clients left by earlier runs first
"$PY" "$VM_ROOT/control/vmc.py" closeall >/dev/null 2>&1 || true
sleep 1
rm -f /tmp/acceptance_gui.txt
"$PY" "$VM_ROOT/control/vmc.py" launch "$VM_PREFIX/bin/st" -e bash -c "cat > /tmp/acceptance_gui.txt" >/dev/null
sleep 2
# EWMH client list. closeall above makes this st the sole managed client;
# st retitles itself to the running command (bash/cat), so match the first
# client whose title is st-like, else the only client on screen.
WID=$("$PY" "$VM_ROOT/control/vmc.py" clients \
  | awk '$3 ~ /^(st|bash|cat)/{print $1; exit} $1 !~ /^0x/{next} !w{w=$1} END{if(!$0){} }')
[ -z "$WID" ] && WID=$("$PY" "$VM_ROOT/control/vmc.py" clients | awk 'NR==1{print $1}')
if [ -n "$WID" ]; then rec PASS T5_gui_app_launched "st window $WID"; else rec FAIL T5_gui_app_launched; fi
if [ -n "$WID" ]; then
  "$PY" "$VM_ROOT/control/vmc.py" focus "$WID" >/dev/null 2>&1
  "$PY" "$VM_ROOT/control/vmc.py" type "GUI_INPUT_$((RANDOM))"
  "$PY" "$VM_ROOT/control/vmc.py" key ctrl d
  sleep 1
  if [ -s /tmp/acceptance_gui.txt ]; then
    rec PASS T6_input_injection "$(cat /tmp/acceptance_gui.txt)"
    rec PASS T8_file_created_via_gui /tmp/acceptance_gui.txt
  else rec FAIL T6_input_injection; rec FAIL T8_file_created_via_gui; fi
  "$PY" "$VM_ROOT/control/vmc.py" shot "$EV/t6_gui_input.png" >/dev/null 2>&1
fi

# 7. agent inspects screenshot (this test itself proves the loop; check PIL parse)
if "$PY" -c "from PIL import Image; im=Image.open('$EV/t4_shot.png'); im.load(); print(im.size)" >/tmp/t7.out 2>&1; then rec PASS T7_agent_screenshot_loop "$(cat /tmp/t7.out)"; else rec FAIL T7_agent_screenshot_loop; fi

# 9. browser
if [ -x "$VM_PREFIX/bin/dillo" ]; then
  cat > /tmp/dillo_test.html <<'EOF'
<html><head><title>Acceptance</title></head><body><h1>ok</h1></body></html>
EOF
  "$PY" "$VM_ROOT/control/vmc.py" launch "$VM_PREFIX/bin/dillo" "file:///tmp/dillo_test.html" >/dev/null
  sleep 3
  if "$PY" "$VM_ROOT/control/vmc.py" clients | grep -qi dillo; then rec PASS T9_browser_works dillo; else rec FAIL T9_browser_works; fi
else rec BLOCKED T9_browser_works "dillo not built"; fi

# 10. tablet bridge
if ss -ltn 2>/dev/null | grep -q "0.0.0.0:6080"; then
  CODE=$(curl -sS -o /dev/null -w '%{http_code}' http://127.0.0.1:6080/ || true)
  [ "$CODE" = "401" ] && rec PASS T10_tablet_auth "401 without credentials" || rec FAIL T10_tablet_auth "http=$CODE"
else rec NOT_TESTED T10_tablet_bridge "start scripts/start_tablet.sh" ; fi

# 11. blender
if "$PY" -c "import bpy" 2>/dev/null; then
  rec PASS T11_blender_installed "$("$PY" -c 'import bpy;print(bpy.app.version_string)')"
  if [ -f "$VM_ROOT/tests/blender_smoke.py" ]; then
    "$PY" "$VM_ROOT/tests/blender_smoke.py" "$EV/t11_blender.png" >>"$RES" 2>&1 \
      && rec PASS T11_blender_render "$EV/t11_blender.png" || rec FAIL T11_blender_render
  fi
else rec NOT_TESTED T11_blender "run scripts/install_blender.sh"; fi

# 11b. file manager: ranger launches inside st under the WM and lists files
if [ -x "$VM_VENV/bin/ranger" ] && TERM=xterm-256color TERMINFO="$VM_PREFIX/share/terminfo" \
   "$VM_VENV/bin/ranger" --version >/dev/null 2>&1; then
  "$PY" "$VM_ROOT/control/vmc.py" launch "$VM_PREFIX/bin/st" -e "$VM_VENV/bin/ranger" "$VM_ROOT" >/dev/null
  sleep 3
  if "$PY" "$VM_ROOT/control/vmc.py" clients | grep -qi ranger; then
    rec PASS T14_file_manager "ranger $(TERM=xterm-256color "$VM_VENV/bin/ranger" --version 2>/dev/null | head -1 | awk '{print $4}')"
    "$PY" "$VM_ROOT/control/vmc.py" closeall >/dev/null 2>&1 || true
  else rec FAIL T14_file_manager; fi
else rec BLOCKED T14_file_manager "ranger not installed"; fi

# 12. UE5 feasibility evidence collected?
[ -f "$VM_ROOT/docs/ue5-feasibility.md" ] && rec PASS T12_ue5_feasibility_doc "docs/ue5-feasibility.md" || rec NOT_TESTED T12_ue5_feasibility

# 13. recovery assets present
[ -x "$VM_ROOT/scripts/recover.sh" ] && [ -s "$VM_ROOT/pins.env" ] \
  && rec PASS T13_recovery_assets "$(wc -l < "$VM_ROOT/pins.env") pins" || rec FAIL T13_recovery_assets

echo "---"; echo "PASS=$ok FAIL=$fail BLOCKED=$blocked" | tee -a "$RES"
````

### File: `tests/blender_smoke.py`

_Headless Blender scene build + Cycles CPU render + .blend round-trip._

````python
#!/usr/bin/env python3
"""Headless Blender smoke test: build a scene, CPU-render it, save + reopen.
Usage: blender_smoke.py [output.png] [output.blend]
Exit 0 only if every step succeeds."""
import os
import sys

import bpy

out_png = os.path.abspath(sys.argv[1] if len(sys.argv) > 1 else "blender_smoke.png")
out_blend = os.path.abspath(sys.argv[2] if len(sys.argv) > 2 else "blender_smoke.blend")

# 1. fresh scene
bpy.ops.wm.read_factory_settings(use_empty=True)
scene = bpy.context.scene

# 2. geometry: cube + UV sphere
bpy.ops.mesh.primitive_cube_add(size=2, location=(-1.4, 0, 0))
cube = bpy.context.object
cube.name = "AgentCube"
bpy.ops.mesh.primitive_uv_sphere_add(radius=1.1, location=(1.4, 0, 0))
sphere = bpy.context.object
sphere.name = "AgentSphere"
mat = bpy.data.materials.new("Red")
mat.diffuse_color = (0.8, 0.1, 0.1, 1.0)
sphere.data.materials.append(mat)

# 3. camera + light. A freshly added camera looks down -Z, so aim it at the
#    origin with a track constraint instead of relying on default rotation.
bpy.ops.object.camera_add(location=(0, -12, 5.5))
cam = bpy.context.object
scene.camera = cam
track = cam.constraints.new(type="TRACK_TO")
track.target = sphere
track.track_axis = "TRACK_NEGATIVE_Z"
track.up_axis = "UP_Y"
bpy.ops.object.light_add(type="SUN", location=(2, -3, 6))
sun = bpy.context.object
sun.data.energy = 3.0
sun.rotation_euler = (0.6, 0.2, 0.4)
# faint world ambient so shadow sides are not pitch black
bpy.data.worlds.new("W")
scene.world = bpy.data.worlds["W"]
scene.world.use_nodes = True
bg = scene.world.node_tree.nodes.get("Background")
bg.inputs[0].default_value = (0.05, 0.05, 0.05, 1.0)
bg.inputs[1].default_value = 0.3

# 4. CPU render settings. EEVEE needs an EGL/GL context (no GPU or vendor
#    driver in the sandbox); Cycles on CPU is fully software and headless.
scene.render.engine = "CYCLES"
scene.cycles.device = "CPU"
scene.cycles.samples = 16
scene.render.resolution_x = 480
scene.render.resolution_y = 320
scene.render.filepath = out_png
scene.render.image_settings.file_format = "PNG"
pre = bpy.context.preferences.addons["cycles"].preferences
pre.compute_device_type = "NONE"
pre.get_devices()
for dev in pre.devices:
    dev.use = dev.type == "CPU"

bpy.ops.render.render(write_still=True)
assert os.path.getsize(out_png) > 10_000, "rendered PNG suspiciously small"

# 5. save and reopen
bpy.ops.wm.save_as_mainfile(filepath=out_blend)
bpy.ops.wm.read_factory_settings(use_empty=True)
bpy.ops.wm.open_mainfile(filepath=out_blend)
names = sorted(o.name for o in bpy.data.objects)
assert "AgentCube" in names and "AgentSphere" in names, f"objects missing after reopen: {names}"

print(f"BLENDER_SMOKE_OK render={out_png} ({os.path.getsize(out_png)} bytes) blend={out_blend} objects={names}")
````

````markdown
## 3. Known limitations / design decisions

- EEVEE GPU rendering impossible (no GPU/EGL); Cycles CPU is the path.
- UE5 hard-blocked: no GPU, no Windows/macOS host, no Vulkan; evidence in

  explicitly disabled): no menu icons; core WM functions unaffected.
- ranger needs a real TERM (xterm-256color) plus TERMINFO pointing at the
  local ncurses database; both are exported by scripts/env.sh/start_desktop.

## 4. Cold-recovery validation (2026-10-26, clean worktree)

A full rebuild was run from a detached worktree containing only tracked
files (zero markers/build dirs). `recover.sh` + `build_extras.sh all` +
`install_blender.sh` rebuilt the whole stack from the 80 pinned sources and
the acceptance suite reported **PASS=15 FAIL=0 BLOCKED=0** on the first
fully clean run after two genuine bugs were caught and fixed during
validation — this is why the cold run matters:

1. **Stage ordering (commit f00a665):** build_openbox ran before
   build_apps, so libffi's `autoreconf` had no autoconf/automake/libtool.

   failing in a fresh tree (the working tree had been hand-patched).
   Replaced by scripts/patches/bison-fseterr-glibc.patch through the
   idempotent apply_patch helper.

markers, and the fixed run skipped every completed stage. Pins written by
the clean fetch were byte-identical (pin names/SHAs) to this tree.

evidence/cold-recovery-blender.png (Cycles CPU render from the rebuild).
````

````markdown
# Agent control surface (`control/vmc.py`)

The Arena agent drives the desktop with ordinary shell calls. No extra LLM,
daemon, or network API is involved — every command speaks X11 directly to the

```bash

export DISPLAY=:99
PY=local/venv/bin/python
```

## Operations

| Goal | Command |
|---|---|
| screen size + pointer | `$PY control/vmc.py info` |
| screenshot | `$PY control/vmc.py shot evidence/x.png` |
| list windows | `$PY control/vmc.py windows` |
| move mouse | `$PY control/vmc.py move 400 300` |
| left click (optionally at x,y) | `$PY control/vmc.py click 1 [x y]` |
| middle/right click | `$PY control/vmc.py click 2` / `click 3` |
| double click | `$PY control/vmc.py doubleclick [x y]` |
| mouse buttons down/up | `$PY control/vmc.py mousedown 1` / `mouseup 1` |
| scroll down/up N | `$PY control/vmc.py scroll 3` / `scroll -3` |
| key / chord | `$PY control/vmc.py key Return` / `key ctrl shift t` |
| type literal text | `$PY control/vmc.py type "echo hello > /tmp/f" ` |
| launch a GUI app | `$PY control/vmc.py launch local/bin/dillo file:///tmp/page.html` |
| raise + focus window | `$PY control/vmc.py focus 0x00600004` |
| close window gracefully | `$PY control/vmc.py close 0x00600004` |
| wait for a window title | `$PY control/vmc.py wait-title Dillo 10` |
| run a shell command with desktop env | `$PY control/vmc.py exec 'xdpyinfo | head'` |

Aliases understood by `key`: ctrl/control, shift, alt, super/win, esc,
return/enter, tab, bs/backspace, del, ins, pgup/pgdn, arrows, caps, print.
Typing handles shifted punctuation and capitals on a US layout.

## The closed feedback loop (verified end-to-end)

1. agent: `vmc.py shot` → reads the returned PNG with its own vision.
2. agent: decides a target coordinate or text.
3. agent: `vmc.py click/type/key` → XTEST events enter the real X server.
4. the real application (st/dillo/vim) changes state.
5. agent: `vmc.py shot` again → verifies visually, or checks the filesystem
   for side effects (e.g. a file the GUI app wrote).
6. on failure: `vmc.py windows`, `run/*.log`, and retries drive diagnosis.

```
````

````markdown
# Bison source selection — dead ends and decision (2026-10-26)

## Decision

Build **GNU bison 3.0.4** from `tar-mirror/gnu-bison` (GitHub mirror of the
upstream release tarball). Pin: `PIN_bison-rel` in `pins.env`.
Stage: `scripts/build_extras.sh s_bison`.

Release tarballs ship pregenerated `scan-*.c`, `parse-gram.c/.h`,
`configure`, `aclocal.m4` and all `Makefile.in`, so neither flex nor a
gnulib/gettext bootstrap is required. One source patch is needed:

- `lib/fseterr.c` — modern glibc (>=2.32) no longer exposes `_IO_ftrylockfile`
  and `__GNU_LIBRARY__` is no longer `1`, which trips the bundled gnulib
  portability `#error`. The stage adds a `__GLIBC__ && __GLIBC_MINOR__`
  branch to the existing `_IO_ERR_SEEN` path (internal libio layout is
  unchanged). Applied idempotently via a guarded `sed`.

## Rejected alternatives

### 1. `gnu-mirror-unofficial/bison` VCS snapshot (tip 2022-01-23, 1183d5e)

Raw VCS tree with empty `gnulib` and `submodules/autoconf` submodules
pointing at unreachable `git://git.savannah.gnu.org` / `git://git.sv.gnu.org`
URLs (egress allowlist: github.com, pypi.org, registry.npmjs.org only).
A full bootstrap was driven manually and got as far as compiling bison
sources, but accumulated unresolved structural problems:

- No `autopoint` on the system; gettext is not installed. A no-op autopoint
  shim plus `gettext-runtime/m4` from `deepin-community/gettext` was needed
  to satisfy `AM_GNU_GETTEXT` / `AM_GNU_GETTEXT_VERSION`.
- `AC_PROG_GNU_M4` is defined only in gettext-tools' m4 archive, absent from
  every reachable packaging; required a hand-written stub macro.
- Version derives from `build-aux/git-version-gen`; a shallow clone yields
  version `UNKNOWN`, rejected by Gnits strictness — needs a fabricated
  `.tarball-version`.
- `po/` and `runtime-po/` gettext scaffolding (`Makefile.in.in`, `Makevars`,
  `LINGUAS`, `Rules-quot`, ...) normally installed by autopoint had to be
  assembled by hand; the gettext-0.23 template's `@top_builddir@` is not
  substituted by this bison's configure, requiring gnulib's variant with a
  literal `top_builddir = ..`.
- gnulib master (2026) is API-skewed against the 2022 bison snapshot:
  `create_pipe_bidi` gained a `dll_dirs` argument; `TEXTSTYLE_H` substitutes
  to a bare `textstyle.h` while the generation rule emits `lib/textstyle.h`
  (prefix variable only in scope inside `gl_INIT`). Checking out gnulib
  commit `71f29a9f4` (2022-01-19) removed the API skew but not the
  TEXTSTYLE_H substitution issue.
- `data/m4sugar/*.m4` and `build-aux/move-if-change` are symlinks into the
  unreachable autoconf submodule (3 dangling links); had to be repointed at
  the locally built autoconf tree and the gnulib checkout.
- Hard blocker: VCS trees generate `scan-code.c`, `scan-gram.c`,
  `scan-skel.c` from `.l` files with **flex**, which is neither installed nor
  downloadable inside the egress allowlist (no Debian mirror access; no
  credible precompiled FOSS binary on GitHub).

### 2. `deepin-community/bison` — Debian-packaged, stripped tree

Missing generated `Makefile.in` and `doc/bison.texi`; not buildable as-is.

### 3. `openela-main/bison` — RPM spec repository

Only `SOURCES/`/`SPECS/` packaging metadata, no upstream source tree.

## Consequence

bison 3.0.4 is older than the `>= 3.6` comment in the old build_stack
header. libxkbcommon release tarballs ship a pregenerated `xkb-parser.c`,
and meson only invokes bison when parser regeneration is explicitly
enabled (it is not in this build), so 3.0.4 is sufficient for the Blender
dependency chain. If a future component genuinely requires bison >= 3.6,
the only free path inside the allowlist is packaging a flex release first
(chicken-and-egg: flex itself needs a bison/flex to build from VCS; a
flex release-tarball mirror on GitHub would have to be located).
````

````markdown
# Unreal Engine 5 — feasibility assessment

**Verdict: BLOCKED — the real UE5 editor cannot be installed or run in this
sandbox.** This document records the evidence, collected on 2026-10-26 from
the live environment (`tests/collect_env.sh`). No mock editor, launcher
screenshot, or substitute is counted as UE5.

## Measured environment

| Resource | Measured value | UE5 Linux requirement (Epic docs, 5.x) |
|---|---|---|
| CPU | 2 vCPU, Intel Xeon @2.60 GHz (KVM guest) | 8–12+ cores recommended |
| RAM | 3.8 GiB total | 16 GiB minimum, 32 GiB recommended |
| Disk | 21 GiB total, ~19 GiB free | ~40 GiB source checkout + 80–120 GiB build artifacts |
| GPU | none: no `/dev/dri`, no `/dev/nvidia*`, no system `libGL` | Vulkan 1.2+ capable GPU with vendor driver (or GL 4.6) |
| Compiler | gcc 12.2 only; no clang | clang 16/17/18 (UBT ships and expects a specific clang; gcc is not supported for the editor) |
| C# / .NET | none | .NET 6/8 SDK for UnrealBuildTool |
| Display | Xvfb, software-only (no render node, no glamor) | Vulkan/GL context with real device support |
| Egress | github.com, pypi.org, registry.npmjs.org only | Epic CDN/Akamai + linked EpicGames GitHub org |

## Hard blockers (each independently sufficient)

1. **No GPU and no render node.** The editor's renderer (RHI) needs Vulkan or
   GL on a real device. `/dev/dri` does not exist, so even Mesa's software
   paths (lavapipe/llvmpipe, which themselves need a render node or
   kms-swrast) have no supported setup here, and glvnd stubs without a vendor
   driver cannot create a context. Running the full editor on CPU rasterization
   is not an Epic-supported configuration and is not viable on 2 vCPUs/3.8 GiB.
2. **Memory is ~4–8x below minimum.** The editor + shader compiler (DXC/SPIR-V)
   routinely exceeds 8 GiB resident on empty projects; 3.8 GiB guarantees OOM
   kills. There is no swap.
3. **Disk cannot hold a source build.** A UE5 source tree plus compiled
   artifacts needs >100 GiB; ~19 GiB is free.
4. **Toolchain mismatch.** Epic's Linux build requires a pinned clang and the
   .NET SDK. Neither is installed, Debian mirrors are unreachable, and the
   Microsoft package host and Epic CDN are outside the egress allowlist.
5. **Licensing/distribution.** UE5 source is only available after accepting
   the EULA and linking an Epic Games account to GitHub (EpicGames org). Epic
   ships no precompiled generic Linux editor binary; the Linux editor is
   source-only. `release-assets.githubusercontent.com` is also blocked here.

## What was tested instead (free, genuinely working)

- **Blender 4.2 LTS via the official `bpy` wheel from PyPI** — installed,
  headless CPU scene creation + render + save/reopen smoke test
  (`tests/blender_smoke.py`). This is the strongest 3D tool this environment
  supports. Blender's GUI also runs on Xvfb with llvmpipe-independent 2D
  drawing; GPU features (CUDA/OptiX/HIP) are unavailable and CPU rendering is
  used.
- **Software-rasterizer route for UE5 (not pursued, documented as
  cost-free-but-infeasible):** Mesa lavapipe could in principle expose a
  software Vulkan ICD, but it still needs far more RAM/CPU than available and
  Epic does not support it for the editor; it would demonstrate a context, not
  a usable editor.

## Re-evaluation trigger

If a future sandbox exposes `/dev/dri/renderD*` with a Vulkan driver,
≥16 GiB RAM, ≥120 GiB free disk, and egress to the Epic CDN, this assessment
should be redone starting from the official "Linux Build Instructions" page on
dev.epicgames.com.
````

# PART 4 — How to download apps (the only two legal channels)

## 4.1 GitHub source packages — `scripts/fetch.sh` + `scripts/manifest.env`

Every compiled component is described by one manifest line:

```text
name|owner/repo|ref|purpose
```

- `name` becomes the checkout directory `src/<name>` and the pin variable
  `PIN_<name>`.
- `ref` of `-` means "default branch"; anything else (e.g. `v3.4.6`,
  `2.80.4`, `pcre2-10.44`) is checked out as a tag for a stable, reproducible
  build.
- fetch.sh runs `git clone --depth 1` (adding `--branch <tag>` when needed),
  then writes the resolved 40-character SHA into `pins.env`. That file is the
  evidence that every rebuild compiles the identical upstream commits.

Fetch everything, or one package:

```bash
bash scripts/fetch.sh                 # all manifest entries
bash scripts/fetch.sh glib pango      # just these two
```

A failed clone makes fetch.sh exit 2 and print `CLONE FAILURES:` — the only
legal response is to retry (network blip) or choose another GitHub mirror;
never reach for a non-allowlisted host.

### Adding a new app from source

1. Append `myapp|some-org/myapp|-|what it is for` to `scripts/manifest.env`.
2. `bash scripts/fetch.sh myapp` — creates `src/myapp` and its pin.
3. Add an `s_myapp()` function to the appropriate build script using the
   env.sh helpers:
   - autotools release tree: `conf_build "$VM_SRC/myapp" --prefix=…` (the
     helper already supplies prefix/libdir and parallel make);
   - meson: `meson_build "$VM_SRC/myapp" -Dopt=value`;
   - cmake: `cmake_build "$VM_SRC/myapp" -DFLAG=ON`;
   - plain makefile (suckless style): `make_build "$VM_SRC/myapp"`.
4. Put `stage myapp s_myapp` into that script's `all)` dispatch in
   dependency order, then run `bash <script> myapp`.

## 4.2 Python packages — pip into the local venv

`recover.sh` phase 1 creates `local/venv` and installs exactly what
`requirements.txt` lists, from PyPI: meson/ninja/cmake (build tools),
python-xlib (GUI control), pillow/mss (screenshots), matplotlib (also
supplies DejaVu TTFs), websockify (tablet bridge), ranger-fm (file
manager). Add Python tooling by appending a pinned line to
requirements.txt and re-running the venv phase (an existing venv is left
untouched, so delete `local/venv` to force a clean reinstall).

## 4.3 What is intentionally NOT downloaded

- Anything outside the three allowed hosts (Google, GNU FTP, apt repos…).
- A standalone Blender binary — the supported path is the PyPI `bpy` wheel
  (Part 6).
- flex/gettext release tarballs — unavailable in the allowlist; the build
  uses a bison release mirror and builds gettext from a GitHub source clone
  instead (see docs/bison-source-notes.md).

# PART 5 — Build order and the one-command bootstrap

With all files from Part 3 in place and the skeleton from Part 2:

```bash
cd arena-vm
bash scripts/recover.sh                 # core desktop
bash scripts/recover.sh --tablet        # core + authenticated tablet bridge
bash scripts/recover.sh --tablet --blender   # everything, ~adds 520 MB wheel
```

Phase map (each writes a marker file under `build/markers/`, so re-runs
resume instead of rebuilding):

1. **venv** — Python toolchain from requirements.txt (skipped if present).
2. **fetch** — all GitHub sources, SHAs into pins.env.
3. **ldconfig** — `echo <prefix>/lib | sudo tee /etc/ld.so.conf.d/…` then
   `sudo ldconfig` (the only sudo use).
4. **build_stack.sh all** — 33 stages: pkgconf, shims, ncurses symlinks,
   zlib/png/expat/freetype/harfbuzz, the full XCB/X11 protocol stack,
   pixman, fontconfig, Xft, xkb data/utils, the X.Org **Xvfb** server,
   xautomation, Xxf86vm.
5. **build_apps.sh all** — m4, autoconf, automake, libtool, openssl, FLTK,
   mbedtls, dillo, libjpeg, libvncserver, x11vnc, vim. **Must precede**
   build_openbox because Openbox's bootstrap calls autoreconf/libtoolize.
6. **build_suckless.sh all** — ncurses (without tests), fonts, dwm, st,
   dmenu.
7. **build_openbox.sh all** — libffi, pcre2 (shared), glib, fribidi, pango
   (Xft backend), libxml2, gettext with a hand-assembled autopoint, Openbox
   itself, then installs config/openbox/* into local/etc/xdg/openbox.
8. With `--blender` only: **build_extras.sh all** (bison 3.0.4 release
   mirror + fseterr patch, libxkbcommon, libglvnd with GLX) then
   **install_blender.sh** (bpy 4.2.0 wheel).
9. **start_desktop.sh** — Xvfb :99 + Openbox (falls back to dwm if the
   binary is missing). `--tablet` additionally backgrounds start_tablet.sh.

Cold-build time is roughly 30–60 minutes depending on CPU. Success ends
with `desktop ready on DISPLAY=:99 (WM=openbox)` and an X.Org version line.
Validate immediately:

```bash
source scripts/env.sh
bash tests/acceptance.sh        # target: PASS=15 FAIL=0 BLOCKED=0
```

# PART 6 — Blender: install, open, render

Blender is the `bpy` PyPI wheel — the full Blender engine usable from
Python; there is no separate GUI binary to launch in this headless design.

```bash
# one-time (or use recover.sh --blender, which also builds the native libs)
bash scripts/build_extras.sh all
bash scripts/install_blender.sh 4.2.0

# verify it imports and see the version
source scripts/env.sh
local/venv/bin/python -c "import bpy; print(bpy.app.version_string)"
```

The native libraries bpy dlopens at import time (libxkbcommon.so.0,
libGL.so.1…) are provided by build_extras and found through
`LD_LIBRARY_PATH` exported by env.sh — do not unset it.

Run the smoke test, which builds a cube + red sphere + camera + sun scene,
renders a PNG, and round-trips a .blend:

```bash
local/venv/bin/python tests/blender_smoke.py evidence/blender.png evidence/blender.blend
# success line: BLENDER_SMOKE_OK render=… blend=… objects=['AgentCube', 'AgentSphere', 'Camera', 'Sun']
```

Open the rendered PNG yourself to confirm the scene is visible (not black).
Rendering uses **Cycles on CPU** with 16 samples. EEVEE needs an EGL/GPU
context; the sandbox has no GPU or vendor GL driver, so a
`Couldn't open libEGL.so.1` message on an EEVEE attempt is expected —
switch the engine to `CYCLES`, set `scene.cycles.device = "CPU"`, exactly as
tests/blender_smoke.py does. To script your own Blender work, write a Python
file using the bpy API and run it with `local/venv/bin/python yourscript.py`.

# PART 7 — Restarting things

| What you want | Command |
|---|---|
| Stop the desktop | `bash scripts/stop_desktop.sh :99` |
| Start/restart the desktop (Openbox) | `bash scripts/start_desktop.sh :99 1280x800x24` |
| Start with dwm instead | `bash scripts/start_desktop.sh :99 1280x800x24 dwm` |
| Restart the tablet bridge (it is killed with the desktop because x11vnc attaches to Xvfb) | `setsid bash scripts/start_tablet.sh :99 6080 > run/tablet.log 2>&1 < /dev/null &` |
| Rebuild one failed stage | `rm -f build/markers/<stage> && bash scripts/<script>.sh <stage>` |
| Re-run everything, resuming from markers | `bash scripts/recover.sh` |
| Full wipe and clean rebuild | `rm -rf src build local run && bash scripts/recover.sh --tablet --blender` |
| Tell Openbox to reload its config | `DISPLAY=:99 local/bin/openbox --reconfigure` |

Health checks:

```bash
pgrep -af "Xvfb :99|bin/openbox|x11vnc|websockify" | grep -v pgrep
ss -ltn | grep -E '5900|6080'     # 5900 = 127.0.0.1 only; 6080 = 0.0.0.0, auth-gated
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:6080/                      # 401 good
curl -s -o /dev/null -w '%{http_code}\n' -u "$(cat run/tablet.cred)" http://127.0.0.1:6080/  # 200 good
ls -la /tmp/.X11-unix/             # X99 socket proves Xvfb is up
tail -n 30 run/Xvfb.log run/openbox.log run/tablet.log
```

# PART 8 — Fixing anything that breaks

## 8.1 Debugging method

1. The build stops with `[FAIL] stage <name> failed`. Note the stage name.
2. Find its function `s_<name>` in the matching script and its build
   directory: autotools → `build/b-<name>/config.log`, meson →
   `build/m-<name>/meson-logs/meson-log.txt`, cmake → `build/c-<name>/`.
3. Fix the root cause (table below covers every failure seen so far).
4. Delete the stage marker if one was written, re-run the single stage,
   then re-run `recover.sh` to continue from where it stopped.
5. Re-run `tests/acceptance.sh`; never claim success without it.

## 8.2 Symptom → cause → exact fix

| Symptom | Cause | Fix |
|---|---|---|
| `autoreconf: command not found` in build_openbox | autotools come from build_apps | Keep recover.sh order: apps → suckless → openbox; run `bash scripts/build_apps.sh all` first |
| `cannot find -lncursesw` / `-ltinfo` | Base image ships versioned runtime `.so.6` but no unversioned dev symlink | `bash scripts/build_stack.sh syslinks` (absolute symlinks into local/lib) |
| vim configure `tgetent() NOT FOUND` | tgetent lives in libtinfo and is not linked transitively | s_vim selects `--with-tlib=tinfo` when local/lib/libtinfo.so exists; ensure the syslinks stage ran |
| ncurses make `DSO missing from command line` in test/ | Test binaries assume transitive tinfo linkage | ncurses is configured `--without-tests`; do not re-enable tests |
| bison `#error Please port gnulib fseterr.c` | glibc ≥2.32 hides `_IO_ftrylockfile` | scripts/patches/bison-fseterr-glibc.patch is applied idempotently via apply_patch in build_extras.sh |
| bison VCS bootstrap failures (flex/autopoint/gnulib) | flex is unobtainable inside the allowlist | Use the bison 3.0.4 release-tarball mirror (tar-mirror/gnu-bison); rationale in docs/bison-source-notes.md |
| xkbcommon meson `found 3.0.4 but need >=3.6` | Hard version gate; the grammar is compatible with 3.0.4 | build_extras.sh strips the gate and maps `parse.error detailed`→`verbose` |
| pkgconf `Dependency "xft" not found` | pkgconf 3.x is case-sensitive; the file is Xft.pc | s_pango symlinks `xft.pc → Xft.pc` in local/lib/pkgconfig |
| meson "value disabled is not boolean" / "unknown option" | feature options take enabled/disabled/auto; booleans take true/false | Match the type in meson_options.txt before retrying the stage |
| autopoint step produced an empty script | A multi-line `--version` string broke a sed expression | s_gettext uses `head -1` and an `[ -s ]` guard; rerun `build_openbox.sh gettext` |
| ranger `setupterm: could not find terminfo database` | curses needs the local terminfo DB and a real TERM | env.sh exports TERMINFO; launch with `TERM=xterm-256color` |
| bpy import: `libxkbcommon.so.0 cannot open` then `libGL.so.1` | The wheel dlopens system-style libs at runtime | env.sh sets LD_LIBRARY_PATH to local/lib; glvnd is built with `-Dglx=enabled` |
| Blender `Couldn't open libEGL.so.1` | No GPU/EGL in the sandbox | Use Cycles CPU (the smoke test already does); EEVEE is infeasible, not broken |
| dillo "Could not establish connection" | Egress allowlist blocks external websites | Expected behavior; demonstrate the browser with `file://` pages |
| Port 6080 returns 401 | HTTP Basic auth challenge | Correct; 200 requires `-u "$(cat run/tablet.cred)"` |
| dillo form field ignores typed text | XTEST clicks do not focus web inputs reliably | Focus the window, `vmc.py key Tab` into the field, then `vmc.py type` |
| make tries to regenerate configure and fails | Git clones flatten mtimes, triggering remake rules | pin_timestamps normalizes source mtimes to 2020-01-01; helpers already call it |
| All binaries vanish after a sandbox reset | src/build/local/run are not persisted | Re-sync Git and rerun recover.sh — the whole design exists for this |
| Tablet bridge dies after a desktop restart | x11vnc binds to a specific Xvfb process | Rerun start_tablet.sh after start_desktop.sh |
| `stage x: command not found` for a hyphenated stage | Dispatch evaluates `s_$1` literally | Use underscore names (openbox_config); hyphen aliases are wired where needed |
| A source repo needs manual edits on every fresh fetch | Clones are disposable | Encode the edit as a scripts/patches/*.patch plus apply_patch, like the bison fix |

## 8.3 Log and state locations

- Build failure detail: `build/b-*/config.log`, `build/m-*/meson-logs/`,
  `build/c-*/CMakeFiles/CMakeOutput.log`.
- Runtime logs: `run/Xvfb.log`, `run/openbox.log`, `run/dwm.log`,
  `run/x11vnc.log`, `run/tablet.log`.
- Resume flags: empty files in `build/markers/` (one per completed stage).
- Credentials: `run/tablet.cred` (never commit; run/ is git-ignored).
- Pin ledger: `pins.env`; package list: `scripts/manifest.env`.

# PART 9 — Daily control of the desktop

Prologue for every GUI command:

```bash
cd arena-vm && source scripts/env.sh
export DISPLAY=:99 XAUTHORITY="$PWD/run/.Xauthority"
PY=local/venv/bin/python
```

`$PY control/vmc.py <command>` reference: `info`, `shot [png]`, `windows`,
`clients` (EWMH app windows — use this one), `focus <id>`, `close <id>`,
`closeall`, `move x y`, `mousedown/mouseup [btn]`, `click [btn] [x] [y]`,
`doubleclick`, `scroll n`, `key <keysym…>`, `type "text"`,
`launch <prog> [args]`, `wait-title <substr> [secs]`, `keysyms`.

Recipes:

```bash
# terminal round-trip
$PY control/vmc.py closeall; sleep 1
$PY control/vmc.py launch local/bin/st -e bash -c "cat > /tmp/out.txt"
sleep 2
WID=$($PY control/vmc.py clients | awk '$3=="bash"{print $1; exit}')
$PY control/vmc.py focus "$WID"
$PY control/vmc.py type "hello from the agent"
$PY control/vmc.py key ctrl d && cat /tmp/out.txt

# local browser form (external sites are blocked)
$PY control/vmc.py launch local/bin/dillo file:///tmp/page.html
sleep 3
WID=$($PY control/vmc.py clients | awk '/Dillo/{print $1; exit}')
$PY control/vmc.py focus "$WID"
$PY control/vmc.py key Tab
$PY control/vmc.py type "what is meant by physics"
$PY control/vmc.py shot evidence/form.png
```

Openbox keybinds: Alt+Return terminal, Alt+r dmenu, Alt+f ranger, Alt+e
vim, Alt+b dillo, Alt+F4 close, Alt+Tab cycle, Alt+F11 maximize,
Ctrl+Alt+arrows change desktop, Alt+left-drag moves, Alt+right-drag
resizes, right-click desktop opens the launcher menu.

# PART 10 — The acceptance contract

`tests/acceptance.sh` is the definition of done. T1 Xvfb alive · T2 Xlib
connects · T3 Openbox owns the WM check (EWMH verified) · T4 screenshot ·
T5 st maps a window · T6 injected keystrokes land · T7 PIL parses frames ·
T8 a file is created through GUI automation · T9 dillo renders · T10 tablet
returns 401 without credentials · T11 bpy imports and Cycles renders (two
sub-checks) · T12 UE5 feasibility document exists · T13 pin ledger present ·
T14 ranger runs. Full stack: **PASS=15 FAIL=0 BLOCKED=0**; core-only runs
legitimately show T10/T11 as NOT_TESTED. Output is mirrored to
`evidence/acceptance.txt`.

## Emergency cheat sheet

```bash
cd arena-vm
bash scripts/recover.sh --tablet            # build/resume + start everything

```
