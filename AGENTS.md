# Presentation production instructions
For any slide task, load `.claude/skills/presentation-production/SKILL.md` and `docs/DESIGN_KNOWLEDGE.md`. This is a DeckCraft CLI adapter repository, not the upstream Rust app. Preserve the existing game-asset pipeline and demos. Do not apply its PSX texture constraints to presentation imagery.
Use `studio` for new presentations; do not write another isolated layout script. Keep geometry preflight, asset provenance, and native text enabled. Never invent research/data. A source URL is provenance, not evidence that its contents have been verified. Distinguish draft, automated-pass, visually-reviewed and Office-tested status. Do not claim absent checks passed. Real 3D requires bpy/Blender; fail clearly if unavailable. Keep installed tools, caches and raw intermediate frames out of Git.
