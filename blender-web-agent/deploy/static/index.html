This build
  • Zero backend. Blender wasm + assets are static files.
  • One plan per page boot: Blender's runtime cannot be re-entered, so each run reloads the tab.
  • Artifacts are reassembled in-page and offered as downloads.
  • Needs a current desktop browser; WebGPU is not required for this build (it is background/headless), WebGL2 is not used for output.
Honest limits
  • This is not Blender's interactive viewport. Edit-mode interaction, EEVEE and physics are out of scope of this build.
  • Cycles CPU only; no GPU path.
  • FBX is compiled out of this Blender build.
